# 拾贴 · ClipTen

个人自用的 macOS 原生菜单栏剪贴板工具，使用 Swift、SwiftUI 和 AppKit，无第三方依赖。

## 使用

运行 `dist/ClipTen.app`，点击菜单栏剪贴板图标即可查看记录。点击一条记录会将完整内容写回系统剪贴板、关闭面板并返回原来的应用，之后照常按 `⌘V` 粘贴。应用不注册任何全局快捷键，也不模拟按键。

- 最多保留 10 条不同内容，最新复制的排在最前；再次复制相同内容会移到最前。
- 与系统剪贴板内容一致的记录在时间旁显示“当前”。恢复旧记录后标记随之移动；复制文件、清空剪贴板或无法读取时取消标记。按完整文字或图片原始字节及格式匹配，不假定第一条就是当前内容。标记不写入磁盘，启动时重新核对，且不会因此重新加入已删除的历史。
- 文字按纯文本保存，列表显示摘要，完整换行和文字在恢复时保留。
- 图片支持剪贴板中的 PNG/TIFF 原始数据，预览使用独立缩略图。
- 忽略 Finder 复制的文件、文件夹和文件承诺，即使文件是图片；复制为文字的路径仍按文字处理。
- 浏览器的“复制图片”和复制到剪贴板的截图可记录；多项目复制、富文本排版和其他自定义格式不在首版范围。
- 默认只在内存保存历史，退出即清空；可在设置中开启保存到硬盘。不联网、不写内容日志、不做云同步。
- 每条记录右侧的垃圾桶按钮可以删除单条。删除带“当前”标记的记录或点击“清空”会同时清空系统剪贴板，删除其他记录只移除历史；开启磁盘保存时会同步更新磁盘历史。
- 为限制资源使用，单条文字上限 5 MiB，单张图片原始数据上限 25 MiB，超限显示提示。最多 10 条，因此极端情况下原始内容可接近 250 MiB。
- 尊重 `org.nspasteboard.ConcealedType` / `TransientType` 标记，但无法识别所有敏感内容。
- 每 0.5 秒检查一次变化，仅变化后读取。应用关闭期间无法记录，也无法保证捕获短于轮询间隔的多次连续覆盖。

没有已保存的历史时，启动会尝试记录当前剪贴板。有磁盘历史时以已保存的记录为准，从启动后的新复制继续记录，避免已删除的条目因为仍在系统剪贴板中而重新出现。若 macOS 显示剪贴板访问提示，请按自己的选择授权；持续自动记录需要系统允许程序读取。访问被拒绝时面板会显示说明，权限恢复后会重新检查。无需辅助功能或屏幕录制权限。

## 设置

点击历史面板右上角的齿轮，打开设置窗口：

- **登录时启动**：使用 macOS 13+ 的 `SMAppService.mainApp` 注册系统登录项。实际行为是在用户登录账户后启动。开关以系统状态为准，系统要求批准或注册失败时会显示说明，并提供系统登录项设置入口。应用不会擅自开启此选项。长期使用建议先将 `.app` 放在固定的应用程序目录，再打开开关；移动应用后可能需要重新注册。开发构建使用 ad-hoc 签名，是否允许注册以本机系统返回为准。
- **清空系统剪贴板前确认**：默认开启。清空全部历史或删除“当前”记录前显示面板内确认提示，取消则不执行。关闭后直接执行；确认期间剪贴板即使变化，也会清空确认时的内容。
- **保存历史到硬盘**：默认关闭。打开时立即保存当前最多 10 条记录，之后新增、删除、清空会异步保存。关闭时删除本应用的历史文件，当前内存记录保留；清理失败则保持原设置并显示错误。

磁盘历史文件：`~/Library/Application Support/ClipTen/history.plist`。使用带版本号的二进制 plist，文字、图片原始数据、顺序、ID 和复制时间一起保存；缩略图不落盘。文件为本地未加密数据，目录权限为 `0700`，文件权限为 `0600`。单文件原子替换防止半写入，串行保存避免旧任务覆盖新记录；没有独立的图片缓存文件需要额外清理。

正常退出会等待保存完成。保存失败会说明错误，让用户决定取消退出还是继续退出；强制结束进程或断电仍可能丢失尚未写完的最近变更。

## 构建与测试

安装 Xcode 或支持 macOS SDK 的 Swift 工具链，在项目目录运行：

```bash
bash scripts/build-app.sh
bash scripts/test.sh
```

产物是 `dist/ClipTen.app`，已进行本机 ad-hoc 签名，可通过 Finder 打开。也可将应用手动复制到“应用程序”文件夹。无需付费开发者账号来本机构建；当前构建没有 Developer ID 签名和公证，跨设备分发可能触发系统安全检查。

默认测试覆盖容量、排序、去重、单条删除、图片字节保留、清空、文件/敏感类型过滤，以及真实临时文件的磁盘往返、删除后重载、清空后重载、关闭保存后的清理、写入失败时的开关状态、并发排队保存与关闭的顺序、文件权限和损坏文件处理。测试使用临时目录和内存偏好替身，不更改实际用户设置或登录项。

真实剪贴板集成测试必须在有图形登录会话且允许访问 pasteboard 服务的普通本机终端运行：

```bash
bash scripts/test.sh --integration
```

集成测试使用 `NSPasteboard.withUniqueName()` 创建独立剪贴板，结束后释放，不会读写系统通用剪贴板。覆盖完整文字/图片往返、图片优先级、缩略图、忽略文件/敏感标记、自己的写回不重复入库及清空行为。受限执行环境可能导致 pasteboard 写入返回 false；此时不能据此认定集成测试通过。默认测试明确跳过这组集成测试。

如果在外层已有沙箱的自动构建环境中，SwiftPM 的内层构建沙箱无法运行，可以给上述脚本追加 `--disable-sandbox`。这只禁用 SwiftPM 的内层构建沙箱，不会解除外层环境限制，也不会授予系统剪贴板权限。模块缓存保存在项目 `.build/` 目录。

## 系统与工具链

- 声明最低运行系统：macOS 13；尚未在旧版本系统逐一验证。
- 首次构建环境：Apple Silicon、macOS 26.6.2、Xcode 26.6、Swift 6.3.3、macOS 26.5 SDK。
- `swift-tools-version: 6.0` 是最低 SwiftPM 工具版本，本项目使用 Swift 6 语言模式，并非锁定 Swift 6.0 编译器。
- macOS 27 是升级兼容目标，当前没有 macOS 27 实机验证。应在 macOS 27 上复核后台剪贴板授权、文字/图片恢复、菜单栏布局、焦点返回和休眠恢复。
- 当前脚本构建本机架构；另一种 CPU 架构应在对应设备构建或另行增加通用二进制打包。

暂未加入搜索或云同步。系统登录启动需要通过实际注销/重新登录验收；自动化测试不会修改本机登录项或注销账户。

## 文件结构

- `Sources/ClipTenCore/`：历史模型、捕获策略和磁盘存储。
- `Sources/ClipTen/`：菜单栏生命周期、剪贴板服务、登录项管理、设置窗口和 SwiftUI 面板。
- `Tests/`：核心测试及可选本机剪贴板集成测试。
- `Resources/Info.plist`：应用标识及菜单栏应用配置。
- `scripts/`：构建、图标生成和测试入口。

## 手动验收

1. 连续复制 11 段不同文字，确认只保留最新 10 条；复制重复文字只移动现有记录。
2. 选择旧文字，在文本编辑器按 `⌘V`，确认 Unicode、换行等完整保留。
3. 复制截图或浏览器图片，确认缩略图；恢复后粘贴到支持图片的目标应用。
4. 在 Finder 复制图片文件或文件夹，确认历史不增加。
5. 删除非当前记录确认系统剪贴板保留；删除当前记录/清空历史，检查确认、取消与关闭确认选项后的直接执行。关闭持久化时，退出重开确认旧历史消失（当前剪贴板可能作为新记录重新出现）。
6. 睡眠/唤醒、系统访问权限拒绝/恢复后重新复制，确认能继续工作。
7. 开启硬盘保存，复制文字和图片，退出重开确认记录/时间/顺序恢复。删除最新条目后重启，确认不会从当前剪贴板复活。
8. 关闭硬盘保存，确认内存记录保留且历史文件被移除；之后退出不应重新生成历史文件。
9. 开启登录时启动，核对系统登录项，再注销并重新登录确认菜单栏图标出现。关闭开关后再次登录应不再自动启动。

剪贴板监测保持每 0.5 秒检查变化计数，定时器允许 0.1 秒调度容差。空闲时权限状态每 5 秒复查；剪贴板变化、打开历史面板或应用激活时立即复查。提示与标记未变化时不重复发布状态更新。权限恢复后会重新识别当前剪贴板。
